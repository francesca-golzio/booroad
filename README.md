# 🗺️ BooRoad
repository: [`booroad`](https://github.com/francesca-golzio/booroad)

BooRoad is a small React Web App for managing group trips and the people who join them. Browse a list of trips, open a trip to see its details and travellers, and add new trips or new travellers through simple forms.

## ✨ Features
- Trips list: the home page shows all available trips.
- Add a trip: a form on the homepage lets you create a new trip. [1]
- Trip details: each trip has its own page with its information.
- travellers list: the detail page lists the travellers on that trip, with their contact details.
- Add a traveller: a form on the detail page lets you register a new traveller with contacts.
- Shared layout: a main layout with navbar (header) and footer wraps every page.

## 🪄 Tech stack
- React (JSX components)
- Vite as build tool and dev server
- Static mock data in JavaScript files (no backend)
